# Security policy

MiLatexAI holds people's Git access tokens, so security reports are taken seriously and answered quickly.

## Reporting a vulnerability

Email **support@milatexai.com** with "Security" in the subject line.

Please include what you found, how to reproduce it, and what an attacker could do with it. Do not
open a public issue for a security problem, and do not access other people's accounts or data while
testing; use your own account.

## What to expect

- An acknowledgement within 3 business days.
- An assessment and, for a confirmed issue, a fix or a plan with a timeline.
- Credit in the fix's commit message if you want it.

## Scope

The hosted service at milatexai.com (the MCP endpoint at https://milatexai.com/mcp, the web pages,
sign-in and the connect forms) and the code in this repository.
